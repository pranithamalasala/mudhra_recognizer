🖐️ Mudhra Recognition System

A web-based Mudhra (Hand Gesture) Recognition System that uses Deep Learning to identify traditional hand mudras from images.
This project combines Computer Vision, Machine Learning, and Web Development to provide real-time and accurate gesture recognition.

🚀 Project Overview

Mudhras play an important role in Indian classical dance, yoga, and cultural expressions.
This project aims to automatically recognize different mudhras using image classification techniques.

Users can upload an image of a hand gesture, and the system predicts the corresponding mudhra using a trained deep learning model.

🧠 Key Features

📷 Upload hand gesture images

🤖 AI-powered mudhra classification

🌐 Web-based user interface

⚡ Fast and accurate predictions

📊 Pre-trained deep learning model integration
